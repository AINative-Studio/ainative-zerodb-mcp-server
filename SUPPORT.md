# Support

Thanks for using `ainative-zerodb-mcp-server`! Here's how to get help.

## Documentation

Start with the [README](./README.md) for setup and tool reference.

## Reporting a bug or requesting a feature

Open an issue in this repo's tracker:
[github.com/AINative-Studio/ainative-zerodb-mcp-server/issues](https://github.com/AINative-Studio/ainative-zerodb-mcp-server/issues).
Bug report and feature request templates are provided when you create a
new issue.

Before filing, please check whether an existing open issue already
covers it. For a bug, include:

- The package version (`npm ls ainative-zerodb-mcp-server`)
- Your Node.js version and MCP client (Claude Desktop, Claude Code, etc.)
- The exact tool call and arguments that failed
- The full error output, not just the last line
